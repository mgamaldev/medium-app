## [1.0.0] - 2026-08-16

### Added
- Automatic read time estimation for saved articles.
- Automated cleanup process for unpublished drafts older than 90 days.
- Weekly content digest system for subscribers.
- Trending articles calculation and tracking.
- Asynchronous delivery system for user notifications.
- User follow functionality.
- Article publishing workflow and event-driven notifications.

### Changed
- Enhanced content visibility controls and management.

### Fixed
- Improved error handling and logging for background tasks.
- Resolved database performance bottlenecks affecting article loading times.
- Fixed image extension handling issues.
